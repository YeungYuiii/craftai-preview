# CraftAI – CityUHK Bright Future (preview)

Static preview of the CraftAI Inauguration page (English + Chinese). No build step.

- English: `index.html`
- Chinese: `zh/index.html` (the EN | 中 switch also works on both pages)
- Assets: `assets/`

## Publish with GitHub Pages
1. Create a **public** repository on GitHub (e.g. `craftai-preview`).
2. Upload everything in this folder to the repository root (keep `.nojekyll`).
3. Repository -> **Settings -> Pages** -> Source: *Deploy from a branch* -> Branch: `main`, folder `/ (root)` -> Save.
4. After a minute the site is live at `https://<your-username>.github.io/craftai-preview/` (Chinese at `.../zh/`).

The page is marked `noindex` so search engines will not list the preview.
